# Documentação do projeto

Esta pasta reúne a documentação metodológica do projeto de análise de movimentos da mão com HD-sEMG.

## Conteúdo

- [`methodology.md`](methodology.md): metodologia atual do processamento e da análise.
- [`analysis_decisions.md`](analysis_decisions.md): justificativas para as principais escolhas de processamento.
- [`project_progress.md`](project_progress.md): resumo do primeiro avanço, resultados obtidos e próximos passos.

O objetivo desta documentação é registrar não apenas **o que foi feito**, mas também **por que cada decisão foi tomada**, facilitando a reprodutibilidade e a discussão científica do trabalho.
